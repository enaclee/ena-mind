# ENΛVERSE 1.0

Android-терминал анализа рынка: Order Flow, ENΛCORE, мультимодальный ИИ-чат, торговый бот, рынок, радар и настройки. Application ID и существующая схема подписи сохранены для обновления приложения; `versionCode` увеличен до 10.

## Возможности

- Семь экранов в HorizontalPager; прокручиваемая нижняя панель с полными названиями, управление графиком внутри холста и единая обработка клавиатуры.
- Ночная, светлая и RGB-тема с цветовым колесом и выбором базы.
- ENΛCORE: ограниченные буферы событий, 12 агентов, матрица Long/Short из 5 Net-целей и 4 горизонтов, контроль свежести и AWO-гейт.
- Ручные пороги бота или мост ENΛCORE. Цель и горизонт ядра фиксируются при входе; сохранены транши, TP/SL, трейлинг, серверная защита и независимые ключи Demo/Testnet/Mainnet.
- Каталог Bybit Linear / Spot / Inverse, поиск металлов и RWA, разделение инструмента по площадке, категории, символу и поколению данных.
- Плавающие системные окна: свечи, матрица, агенты, стакан и HUD. Перемещение, размер, поворот 0–360°, прозрачность и сохранение расположения.
- Независимые каналы уведомлений, справочник семи разделов и [политика конфиденциальности](docs/PRIVACY.md).

## Что означает матрица

Ячейка оценивает историческую частоту достижения цели движения цены после расчётной комиссии в заданном горизонте. Используются закрытые минутные свечи, неперекрывающиеся окна, сглаживание Лапласа и нижняя граница Wilson. AWO требует минимум 20 наблюдений и нижнюю границу не менее 50%, свежие сделки/стакан, свежие свечи и допустимый спред.

Это эмпирическая оценка на доступной истории, а не доказанная вневыборочная калибровка, вероятность прибыльной сделки со стопом или гарантия дохода. Цели выражены в движении цены, не ROE. Матрица не включает проскальзывание, будущий фандинг и конкуренцию TP/SL. На длинных горизонтах до накопления истории сигнал может оставаться нейтральным.

## Границы исполнения

| Рынок | Анализ | Paper | Биржевое исполнение |
| --- | --- | --- | --- |
| Bybit Linear / USDT, включая доступные металлы | Да | Да | Demo / Testnet / Mainnet |
| Спот / USDT | Да | Long, 1× | Нет |
| Инверсные контракты, прочие котируемые валюты | Да | Нет | Нет |

Клиент исполнения рассчитан на линейные позиции в USDT. Неподдерживаемые категории блокируются до отправки ордера. Наличие инструмента в публичном каталоге не гарантирует наличие на Demo или Testnet; отклонения биржи отображаются в приложении. Смена инструмента и режима заблокирована при работающем боте или незавершённой позиции. Ошибка проверки/закрытия позиции не удаляет её из локального состояния.

Основные данные ENΛCORE получает от существующих Kotlin-потоков. Python добирает только недостающую межбиржевую котировку с ограничением частоты. Отсутствие сопоставимой котировки металла нейтрализует только соответствующего агента. Резервный поток другой площадки помечается источником; он не заменяет требование свежего Bybit-потока для AWO.

## Проверка и сборка

GitHub Actions выполняет:

```sh
python3 -m unittest discover -s app/src/test/python -v
python3 ena-mind/tests/run_tests.py
gradle :app:testDebugUnitTest :app:assembleDebug --no-daemon
```

Среда CI: JDK 21, Python 3.11, Gradle 9.3.1 и Android SDK. APK и отчёты тестов доступны в Artifacts успешного запуска **Build ENAVERSE APK**. Необходимо проверить приложение на целевом телефоне: жесты графика, клавиатуру, восстановление разрешений и виджеты после сворачивания/поворота. Автоматическая сборка не проверяет реальное исполнение ордеров или поведение прошивки конкретного устройства.

## Публикация

Документ политики включён в приложение и репозиторий. Для Google Play разместите его также по публичному веб-URL и заполните Data safety по фактической сборке и подключённым сервисам. Декларация не заменяется наличием текста в APK. Публикация в магазине в этот репозиторный выпуск не входит.

Технические источники: [Bybit Instruments](https://bybit-exchange.github.io/docs/v5/market/instrument), [Bybit public trades](https://bybit-exchange.github.io/docs/v5/websocket/public/trade), [Android foreground-service timeout](https://developer.android.com/develop/background-work/services/fgs/timeout), [Google Play User Data](https://support.google.com/googleplay/android-developer/answer/10144311).
